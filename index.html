Linux Basics

This page is a short primer on the concepts you'll run into constantly in the Fedora and Arch tabs. If you already know your way around a terminal, feel free to skip straight to your distro's tab — this is here for whenever you need it.

Why this matters Every command in this guide assumes you understand roughly what it's doing. Nothing here will make you an expert overnight, but it removes the "am I about to break something" feeling that copy-pasting blind gives you.

Terminal & sudo

The terminal is a text window where you type commands instead of clicking. It looks intimidating at first, but it's just a more direct way of telling your computer what to do — nothing typed here is inherently more dangerous than clicking buttons, it's just less forgiving of typos.

sudo

sudo stands for "superuser do." Normal actions run with your regular user permissions, which can't touch core system files — that's a safety feature. sudo temporarily grants a single command administrator rights, the same way Windows asks "Allow this app to make changes?" You'll be asked for your password the first time in a while.

Rule of thumb Only run sudo commands you understand, and only from sources you trust. It can modify or delete anything on the system if told to.

Common flags you'll see

  • -y — auto-answers "yes" to prompts, so the command doesn't stop and wait for you
  • -S — used by pacman/yay to mean "sync/install a package"
  • -R — used by pacman to mean "remove a package"

Package managers

A package manager installs, updates, and removes software for you — instead of downloading random installers off the internet, you ask the package manager for a program by name and it handles the rest, including dependencies.

  • Fedora uses dnf — installs from Fedora's official repositories.
  • Arch uses pacman for official packages, plus the AUR (Arch User Repository) for community-submitted ones, accessed through a helper like yay.
Why the AUR needs a "helper" AUR packages are just build recipes, not ready-made binaries — yay downloads the recipe, compiles it, and installs it, so it feels the same as installing an official package.

Flatpak vs native packages

Flatpak is a universal app format that works the same way on any distro — the app runs in a sandbox, bundling most of its own dependencies instead of relying on your system's. Flathub is the main store/repository of Flatpak apps.

Native package (dnf/pacman)Flatpak
Tightly integrated with the systemSandboxed, isolated from the system
Smaller download (shares system libraries)Larger download (bundles its own libraries)
Same version across all appsEach app can use its own library versions

Neither is "better" — this guide uses whichever is more reliable for a given app, and says so explicitly each time.

Where things live

A few folders worth knowing by name:

  • ~ or /home/yourname — your personal folder, same idea as C:\Users\yourname on Windows
  • /etc — system-wide configuration files
  • /usr/bin — where most installed programs actually live
  • ~/.config — where most apps store their personal settings

Staying updated

Unlike Windows, updates on Linux are usually one command and don't force a restart mid-task. Still, get in the habit of running them regularly — outdated systems are the most common cause of "why won't this install" problems.

# Fedora
sudo dnf update -y

# Arch
sudo pacman -Syu
Kernel updates If an update includes a new kernel, reboot before installing anything else — especially GPU drivers, which are tied to the exact kernel version.

Recommended Apps

A grab-bag of apps worth having on any fresh install, beyond the core gaming stack covered in the Fedora/Arch tabs. Grouped by what you'd actually use them for — install whatever's relevant to you, skip the rest.

Fedora vs Arch commands Every app card below shows both the dnf and pacman/yay command. Flatpak installs are the same on either distro.

Gaming Extras

Beyond Steam/Lutris/ProtonPlus — for specific situations.

Gamescope

Valve's micro-compositor for resolution/scaling fixes

Runs a game in its own mini-compositor with a fixed internal resolution, then scales it to your display. Fixes games that render at the wrong resolution or won't respect your monitor's native one — also what the Steam Deck uses under the hood.

# Fedora
sudo dnf install -y gamescope

# Arch
sudo pacman -S gamescope

Protontricks

Runs winetricks commands inside a specific game's Proton prefix

Some games need a specific DLL, font, or Windows component that isn't installed by default. Protontricks lets you run those winetricks fixes targeted at one game's Proton environment, instead of guessing blind.

# Fedora
flatpak install -y flathub com.github.Matoking.protontricks

# Arch
yay -S protontricks

System Monitoring

btop

A much nicer terminal system monitor than top/htop

Shows CPU, memory, disk, network, and per-process stats with a clean, mouse-clickable terminal UI. Good for spotting what's actually eating resources while a game runs.

# Fedora
sudo dnf install -y btop

# Arch
sudo pacman -S btop

GOverlay

GUI for configuring MangoHud

Instead of hand-editing MangoHud's config file, GOverlay gives you toggles and sliders for what the overlay shows and where — useful once you're past the "just get it working" stage.

# Fedora
flatpak install -y flathub io.github.benjamimgois.goverlay

# Arch
yay -S goverlay

Media

VLC

Plays almost any video/audio format, no separate codec hunting

Good fallback whenever something won't play through your default media app — VLC bundles its own codecs, so it usually works even before you've set up the codec packages in this guide.

# Fedora
sudo dnf install -y vlc

# Arch
sudo pacman -S vlc

OBS Studio

Screen/gameplay recording and streaming

The standard tool for recording gameplay clips or streaming to Twitch/YouTube. Works well alongside MangoHud if you want the overlay visible in recordings.

# Fedora
flatpak install -y flathub com.obsproject.Studio

# Arch
sudo pacman -S obs-studio

Productivity

GIMP

Free, full-featured image editor

# Fedora
sudo dnf install -y gimp

# Arch
sudo pacman -S gimp

VS Code / VSCodium

Code editor — VSCodium is the same editor without Microsoft's telemetry

# Fedora (VS Code, via Microsoft's repo) or Flatpak VSCodium:
flatpak install -y flathub com.vscodium.codium

# Arch (AUR)
yay -S vscodium-bin

Timeshift

One-click system snapshots and restore

Cheap insurance before a risky change — like installing a new GPU driver. If something breaks, roll back to the last snapshot instead of reinstalling.

# Fedora
sudo dnf install -y timeshift

# Arch
sudo pacman -S timeshift

KeePassXC

Offline password manager

# Fedora
sudo dnf install -y keepassxc

# Arch
sudo pacman -S keepassxc

Files & Archives

Already covered in the Fedora/Arch Extra Tools pages — p7zip + unrar for archives, and Gearlever for managing AppImages. Nothing extra needed here beyond that.

Gaming on Fedora

Everything worth doing on a fresh Fedora install before you start gaming, in the order to do it. Every section explains what a command does and why it's there — check the Linux Basics tab first if terms like sudo or "repository" are new.

Before you copy-paste anything Read each command before running it. Nothing here is dangerous if followed in order, but understanding what a line does before running it is a good habit on any system.

Right After Install

These four steps come first because almost everything later — drivers, codecs, extra apps — depends on them.

1. Enable RPM Fusion

Fedora ships very minimal by default for legal/licensing reasons. RPM Fusion is a third-party repository that unlocks the software Fedora can't include out of the box — NVIDIA drivers, some codecs, and more. Almost every later step needs it.

# Free repo — most stuff you need
sudo dnf install -y https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm

# Nonfree repo — NVIDIA drivers, some codecs
sudo dnf install -y https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

# Sync it all up
sudo dnf group upgrade core -y
sudo dnf check-update
Free vs nonfree, quickly Free = open-source software Fedora can legally redistribute. Nonfree = proprietary software (NVIDIA drivers, certain codecs) Fedora can't ship by default due to licensing.

2. Update everything

Fresh installs almost always ship slightly outdated. Updating first avoids installing drivers or games against outdated system libraries.

sudo dnf update -y
# If it updated the kernel, reboot before continuing:
sudo reboot

3. Update firmware

This is your hardware's own firmware — GPU, motherboard, SSD — not the OS. Newer firmware can fix stability issues and even affect gaming performance.

sudo fwupdmgr get-devices
sudo fwupdmgr refresh --force
sudo fwupdmgr get-updates
sudo fwupdmgr update
Reboot required If any firmware updated, reboot before moving on.

4. Set up Flathub

Fedora includes a limited, curated version of Flatpak by default. Flathub is the real, full app store behind it — several apps later in this guide (Steam's Flatpak build, ProtonPlus, Heroic, Bottles) come from here.

flatpak remote-delete fedora
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak update --appstream

NVIDIA Drivers

Read this before starting NVIDIA on Linux takes more steps than AMD/Intel, and it's the step most likely to cause a black screen if rushed. Disable Secure Boot in your BIOS first (or learn to sign kernel modules yourself), and make sure you've already updated + rebooted. 
# Kernel headers and build tools the driver needs to compile
sudo dnf install -y kernel-devel kernel-headers gcc make dkms acpid \
  libglvnd-glx libglvnd-opengl libglvnd-devel pkgconfig

RTX 4000-series or newer only: Fedora needs one extra setting so it builds the open-source kernel module correctly.

sudo sh -c 'echo "%_with_kmod_nvidia_open 1" > /etc/rpm/macros.nvidia-kmod'

Now install the driver itself:

sudo dnf install -y akmod-nvidia xorg-x11-drv-nvidia-cuda

This compiles the driver in the background and takes 5–15 minutes. Watch progress with:

sudo journalctl -f -u akmods

Once it's done, reboot and confirm it worked:

sudo reboot
nvidia-smi

If nvidia-smi shows your GPU info, you're done. If not:

sudo akmods --force --kernels $(uname -r)
sudo reboot
Stuck at a black screen or 800×600? Boot into an older kernel from GRUB's "Advanced Options," then run sudo akmods --kernels $(uname -r) --rebuild and reboot. Still broken? Check sudo journalctl -u akmods and dmesg | grep -i nvidia for the actual failure.

After future kernel updates, NVIDIA sometimes needs a manual rebuild:

sudo akmods --kernels $(uname -r) --rebuild
sudo reboot

AMD & Intel Drivers

These generally work out of the box, but installing the full Mesa/Vulkan stack makes sure nothing games need is missing.

# Both AMD & Intel
sudo dnf install -y mesa-dri-drivers mesa-vulkan-drivers vulkan-loader mesa-libGLU

# AMD only — smoother video playback
sudo dnf install -y mesa-va-drivers-freeworld mesa-vdpau-drivers-freeworld

# Intel, newer GPUs
sudo dnf install -y intel-media-driver

# Intel, older GPUs
sudo dnf install -y libva-intel-driver

That's genuinely it — no extra setup needed for AMD or Intel.

Video & Codecs

Fedora ships with almost no media codecs by default due to licensing. Games and launchers that show embedded video — trailers, cutscenes, streaming overlays — need this to play anything at all.

sudo dnf4 group install multimedia
sudo dnf swap 'ffmpeg-free' 'ffmpeg' --allowerasing
sudo dnf upgrade @multimedia --setopt="install_weak_deps=False" --exclude=PackageKit-gstreamer-plugin
sudo dnf group install -y sound-and-video

Hardware acceleration

Lets your GPU handle video decoding instead of your CPU doing all the work — matters if you record or stream gameplay.

sudo dnf install -y ffmpeg-libs libva libva-utils

NVIDIA users, also run:

sudo dnf install -y libva-nvidia-driver

Steam

Steam

The main store and launcher for PC gaming on Linux

Steam bundles Proton, Valve's compatibility layer built on Wine, which translates Windows game calls into something Linux understands. Most Windows-only games on your library will just work once Steam is installed — no extra setup.

sudo dnf install -y steam
Newer NVIDIA GPU + Steam won't launch? Usually missing dependencies in the RPM build. Switch to the Flatpak version instead: 
sudo dnf remove steam
flatpak install -y flathub com.valvesoftware.Steam

ProtonPlus

ProtonPlus

Installs and manages extra Proton, Wine, and DXVK/VKD3D builds

Steam's built-in Proton doesn't cover every game. ProtonPlus is a modern GTK app that installs community-maintained compatibility tools — most importantly Proton-GE (a Proton build with extra game-specific fixes) — and manages updates for them from one place. It's the actively-maintained successor to the older ProtonUp-Qt tool.

flatpak install flathub com.vysp3r.ProtonPlus
# Fedora also offers it via COPR:
sudo dnf -y copr enable wehagy/protonplus
sudo dnf install protonplus

Using it

Open ProtonPlus → install a Proton-GE build → in Steam, right-click a game → Properties → Compatibility → tick "Force the use of a specific Steam Play compatibility tool" → select the GE build you installed.

GameMode & MangoHud

GameMode

Auto-tunes your system for performance while a game runs

GameMode temporarily switches your CPU governor to performance mode, and can adjust other system settings, only while a game is running — then reverts automatically when you quit. Zero configuration needed for the basic benefit.

MangoHud

On-screen overlay: FPS, CPU/GPU temps, frame times

Useful for actually seeing whether a setting change helped, or spotting whether a game is CPU-bound or GPU-bound.

sudo dnf install -y gamemode mangohud

Add this to a game's Steam launch options (right-click game → Properties → Launch Options) to enable both at once:

gamemoderun mangohud %command%

Lutris

Lutris

Manages everything Steam doesn't

Battle.net, Epic, GOG, older Windows titles, and emulators. Lutris manages the Wine prefix for you and runs community-submitted install scripts, so you're not hand-configuring each game from scratch.

sudo dnf install -y lutris
# or the Flatpak version:
flatpak install -y flathub net.lutris.Lutris

Heroic & Bottles

Heroic Games Launcher

Native-feeling launcher for Epic Games Store and GOG

If most of your non-Steam library is Epic or GOG specifically, Heroic gives a cleaner, purpose-built interface than Lutris for just those two stores — library view, cloud saves, and per-game Proton/Wine settings.

flatpak install -y flathub com.heroicgameslauncher.hgl

Bottles

Isolated Wine "bottles" for individual Windows apps and games

Each "bottle" is a separate, sandboxed Wine environment — so a tweak or install for one game can't break another. Handy for older or oddball Windows programs that don't have a Steam/Epic/GOG install at all.

flatpak install -y flathub com.usebottles.bottles

Extra Tools

Small utilities that come up constantly once you're actually using the system day to day.

Archive support

Sooner or later you'll need to open a .rar — game mod archives especially love this format.

sudo dnf install -y p7zip p7zip-plugins unrar btop

AppImage support

Some game launchers and tools only ship as AppImages — self-contained apps that need FUSE to run.

sudo dnf install -y fuse fuse-libs
# optional GUI manager for organizing them:
flatpak install -y flathub it.mijorus.gearlever

Cleanup

Worth running occasionally to reclaim disk space, especially with big game installs.

sudo dnf clean all
sudo dnf autoremove -y

Gaming on Arch

Same shape as the Fedora tab, adapted to pacman and the AUR. Check the Linux Basics tab if terms like "AUR helper" or "multilib" are new.

Before you copy-paste anything Read each command before running it — especially anything touching drivers or the bootloader.

Right After Install

1. Update the system

Always update before installing anything new — Arch moves fast, and installing packages against an outdated system is the most common cause of breakage.

sudo pacman -Syu

2. Enable multilib

Multilib provides 32-bit libraries. Most games and Steam itself need this — without it, many games simply won't launch.

# Uncomment the [multilib] section in /etc/pacman.conf, then:
sudo pacman -Sy

3. Install an AUR helper

The AUR hosts community packages not in the official repos — ProtonPlus and a few gaming tools live here. yay wraps the build process so installing from the AUR feels the same as installing an official package.

sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay && makepkg -si

NVIDIA Drivers

Read this before starting Disable Secure Boot in your BIOS first, and make sure you've already updated and rebooted. 
sudo pacman -S nvidia nvidia-utils lib32-nvidia-utils nvidia-settings

Reboot, then confirm it worked:

sudo reboot
nvidia-smi
Using a custom kernel (e.g. linux-zen)? Install the matching headers package (linux-zen-headers, etc.) and the matching nvidia-dkms package instead of plain nvidia, so the driver rebuilds automatically on kernel updates.

AMD & Intel Drivers

Open-source Mesa drivers handle both well out of the box.

# AMD
sudo pacman -S mesa lib32-mesa vulkan-radeon lib32-vulkan-radeon

# Intel
sudo pacman -S mesa lib32-mesa vulkan-intel lib32-vulkan-intel

Video & Codecs

Arch ships most codecs by default, but these fill gaps for hardware-accelerated playback — useful if you record or stream gameplay.

sudo pacman -S gst-plugins-good gst-plugins-bad gst-plugins-ugly gst-libav
sudo pacman -S libva-utils

NVIDIA users, also run:

sudo pacman -S libva-nvidia-driver

Steam

Steam

The main store and launcher for PC gaming on Linux

Bundles Proton, Valve's Wine-based compatibility layer. Most games work out of the box once Steam and multilib are set up.

sudo pacman -S steam

ProtonPlus

ProtonPlus

Installs and manages extra Proton, Wine, and DXVK/VKD3D builds

Installs and updates community Proton builds — most importantly Proton-GE — from one place, and can set them per-game directly in Steam.

yay -S protonplus

Using it

Open ProtonPlus → install a Proton-GE build → in Steam, right-click a game → Properties → Compatibility → tick "Force the use of a specific Steam Play compatibility tool" → select the GE build you installed.
