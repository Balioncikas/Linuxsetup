Gaming on Fedora

This walks through everything worth doing on a fresh Fedora install before you start gaming. Go top to bottom in the sidebar the first time — each page explains what the commands do and why, so you're never just copy-pasting blind.

Quick command heads-up sudo means "run as administrator" — you'll be asked for your password. The -y flag auto-confirms prompts so you don't have to press Enter a bunch of times.
Before you copy-paste anything Read each command before running it. None of this is dangerous if followed in order, but understanding what a line does before running it is a good habit on any system.

Right After Install

These four steps come first because almost everything later (drivers, codecs, extra apps) depends on them being done.

1. Enable RPM Fusion

Fedora ships very minimal by default for legal/licensing reasons — RPM Fusion is the repository that unlocks the software Fedora can't include out of the box, like NVIDIA drivers and video codecs. Almost every step later in this guide needs it.

# Free repo — most stuff you need
sudo dnf install -y https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm

# Nonfree repo — NVIDIA drivers, some codecs
sudo dnf install -y https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

# Sync it all up
sudo dnf group upgrade core -y
sudo dnf check-update

2. Update everything

Fresh installs almost always ship with slightly outdated packages. Updating first avoids installing drivers or games against outdated system libraries.

sudo dnf update -y
# If it updated the kernel, reboot before continuing:
sudo reboot

3. Update firmware

This is your hardware's own firmware (not the OS) — GPU, motherboard, SSD, etc. Newer firmware can fix stability issues and even affect gaming performance.

sudo fwupdmgr get-devices
sudo fwupdmgr refresh --force
sudo fwupdmgr get-updates
sudo fwupdmgr update
Reboot required If any firmware updated, reboot before moving on — there's no way around this one.

4. Set up Flathub

Fedora includes a limited, curated version of Flatpak by default. Flathub is the real, full app store behind it — several gaming tools later in this guide (like Steam's Flatpak version) come from here.

flatpak remote-delete fedora
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak update --appstream

Graphics Drivers

The right GPU driver is the single biggest factor in how well games run. Pick the section for your hardware.

AMD & Intel — the easy ones

These generally work out of the box, but installing the full Mesa/Vulkan stack makes sure you're not missing anything games need.

# Both AMD & Intel
sudo dnf install -y mesa-dri-drivers mesa-vulkan-drivers vulkan-loader mesa-libGLU

# AMD only — smoother video playback
sudo dnf install -y mesa-va-drivers-freeworld mesa-vdpau-drivers-freeworld

# Intel, newer GPUs
sudo dnf install -y intel-media-driver

# Intel, older GPUs
sudo dnf install -y libva-intel-driver

That's it — no extra setup needed for AMD or Intel.

NVIDIA — more involved, but manageable

Read this before starting NVIDIA on Linux takes more steps than AMD/Intel. Disable Secure Boot in your BIOS first (or learn to sign kernel modules yourself if you want to keep it on), and make sure you've already done the update + reboot from the previous page. 
# Kernel headers and build tools the driver needs to compile
sudo dnf install -y kernel-devel kernel-headers gcc make dkms acpid \
  libglvnd-glx libglvnd-opengl libglvnd-devel pkgconfig

RTX 4000-series or newer only: Fedora needs one extra setting so it builds the open-source kernel module correctly.

sudo sh -c 'echo "%_with_kmod_nvidia_open 1" > /etc/rpm/macros.nvidia-kmod'

Now install the driver itself:

sudo dnf install -y akmod-nvidia xorg-x11-drv-nvidia-cuda

This step compiles the driver in the background and takes 5–15 minutes. You can watch its progress with:

sudo journalctl -f -u akmods

Once it's done, reboot, then confirm it worked:

sudo reboot
nvidia-smi

If nvidia-smi shows your GPU info, you're done. If not:

sudo akmods --force --kernels $(uname -r)
sudo reboot
Stuck at a black screen or 800×600? Boot into an older kernel from the GRUB "Advanced Options" menu, then run sudo akmods --kernels $(uname -r) --rebuild and reboot. If it's still broken, check sudo journalctl -u akmods and dmesg | grep -i nvidia for what actually failed.

After future kernel updates, NVIDIA sometimes needs a manual rebuild:

sudo akmods --kernels $(uname -r) --rebuild
sudo reboot

Video & Codecs

Fedora ships with almost no media codecs by default due to licensing. Games and launchers that show embedded video (trailers, cutscenes, streaming overlays) need this to actually play anything.

sudo dnf4 group install multimedia
sudo dnf swap 'ffmpeg-free' 'ffmpeg' --allowerasing
sudo dnf upgrade @multimedia --setopt="install_weak_deps=False" --exclude=PackageKit-gstreamer-plugin
sudo dnf group install -y sound-and-video

Hardware acceleration

This lets your GPU handle video decoding instead of your CPU doing all the work — matters if you're recording or streaming gameplay.

sudo dnf install -y ffmpeg-libs libva libva-utils

NVIDIA users, also run:

sudo dnf install -y libva-nvidia-driver

Steam & Proton-GE

Steam is the main way you'll play Windows games on Linux, thanks to Proton (Valve's Windows compatibility layer built on Wine).

sudo dnf install -y steam

That's genuinely it for most games — many just work with Steam's built-in Proton.

Newer NVIDIA GPU + Steam won't launch? This is usually missing dependencies in the RPM version. Switch to the Flatpak build instead: 
sudo dnf remove steam
flatpak install -y flathub com.valvesoftware.Steam

Proton-GE — for extra compatibility

Proton-GE is a community build of Proton with extra fixes for games that don't run well on Valve's stock version. Install it through ProtonUp-Qt, then pick it per-game in Steam → right-click the game → Properties → Compatibility.

flatpak install flathub net.davidotek.pupgui2

GameMode & MangoHud

GameMode automatically tunes your CPU/GPU governor for performance while a game runs, then reverts it when you close the game. MangoHud is an on-screen overlay showing FPS, CPU/GPU temps, and frame times — useful for spotting bottlenecks.

sudo dnf install -y gamemode mangohud

Add this to a game's Steam launch options (right-click game → Properties → Launch Options) to enable both at once:

gamemoderun mangohud %command%

Lutris

Lutris handles everything Steam doesn't: Battle.net, Epic Games, GOG, emulators, and older titles. It manages Wine prefixes for you and runs community install scripts so you're not hand-configuring each game.

sudo dnf install -y lutris
# or, the Flatpak version:
flatpak install -y flathub net.lutris.Lutris

Extra Tools

Small utilities that come up constantly once you're actually using the system day to day.

Archive support

Sooner or later you'll need to open a .rar — game mod archives especially love this format.

sudo dnf install -y p7zip p7zip-plugins unrar btop

AppImage support

Some game launchers and tools only ship as AppImages — self-contained apps that need FUSE to run.

sudo dnf install -y fuse fuse-libs
# optional GUI manager for organizing them:
flatpak install -y flathub it.mijorus.gearlever

Cleanup

Worth running occasionally to reclaim disk space, especially with big game installs.

sudo dnf clean all
sudo dnf autoremove -y

Gaming on Arch

Same idea as the Fedora side, adapted to pacman and the AUR. Go top to bottom the first time through.

Quick command heads-up sudo runs a command as administrator. yay is an AUR helper — it lets you install community packages the same way you install official ones.
Before you copy-paste anything Read each command before running it — especially anything touching drivers or the bootloader.

Right After Install

1. Update the system

Always update before installing anything new — Arch moves fast, and installing packages against an outdated system is the most common cause of breakage.

sudo pacman -Syu

2. Enable multilib

Multilib provides 32-bit libraries. Most games and Steam itself need this — without it, many games simply won't launch.

# Uncomment the [multilib] section in /etc/pacman.conf, then:
sudo pacman -Sy

3. Install an AUR helper

The AUR (Arch User Repository) hosts community packages that aren't in the official repos — Proton-GE's installer and a few gaming tools live here.

sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay && makepkg -si

Graphics Drivers

AMD & Intel — the easy ones

Open-source Mesa drivers handle both well out of the box.

sudo pacman -S mesa lib32-mesa vulkan-radeon lib32-vulkan-radeon   # AMD
sudo pacman -S mesa lib32-mesa vulkan-intel lib32-vulkan-intel     # Intel

NVIDIA — more involved, but manageable

Read this before starting Disable Secure Boot in your BIOS first, and make sure you've updated and rebooted already. 
sudo pacman -S nvidia nvidia-utils lib32-nvidia-utils nvidia-settings

Reboot, then confirm it worked:

sudo reboot
nvidia-smi
Using a custom kernel (e.g. linux-zen)? Install the matching headers package (linux-zen-headers, etc.) and the matching nvidia-dkms package instead of plain nvidia, so the driver rebuilds automatically on kernel updates.

Video & Codecs

Arch ships most codecs by default, but these fill in gaps for hardware-accelerated playback — useful if you record or stream gameplay.

sudo pacman -S gst-plugins-good gst-plugins-bad gst-plugins-ugly gst-libav
sudo pacman -S libva-utils

NVIDIA users, also run:

sudo pacman -S libva-nvidia-driver

Steam & Proton-GE

sudo pacman -S steam

Most games work out of the box with Steam's built-in Proton.

Proton-GE — for extra compatibility

A community Proton build with extra game-specific fixes. Install via ProtonUp-Qt from the AUR, then select it per-game in Steam → Properties → Compatibility.

yay -S protonup-qt

GameMode & MangoHud

GameMode auto-tunes CPU/GPU performance while a game runs. MangoHud is an FPS/temperature overlay.

sudo pacman -S gamemode lib32-gamemode mangohud lib32-mangohud

Add to a game's Steam launch options:

gamemoderun mangohud %command%

Lutris

For Battle.net, Epic, GOG, and emulators — manages Wine prefixes and runs community install scripts.

sudo pacman -S lutris

Extra Tools

Archive support

sudo pacman -S p7zip unrar

AppImage support

sudo pacman -S fuse2

Cleanup

sudo pacman -Sc
sudo pacman -Qtdq | sudo pacman -Rns -
